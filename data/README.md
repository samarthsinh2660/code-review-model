# Local datasets

Keep immutable downloads in `raw/`, conversion outputs in `interim/`, and audited, split-ready records in `processed/`. These directories are ignored by Git. Record source URL, release/commit, retrieval date, license, SHA-256, schema, label rules, and retained/rejected counts for each source in the relevant audit document.

Do not treat advisory metadata as automatically labelled source-code functions. Split manifests must keep related variants and vulnerable/fixed pairs together.
